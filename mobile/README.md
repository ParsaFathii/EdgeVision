# EdgeVision — کلاینت موبایل (Flutter)

کلاینت رسمی موبایل و دسکتاپ پروژهٔ **EdgeVision** — پلتفرم تحلیل ویدئوی
بلادرنگ — با رابط کاربری کاملاً فارسی و راست‌به‌چپ.

Copyright © ۲۰۲۶ پارسا فتحی — مجوز Apache-2.0.

## امکانات

- **رابط فارسی RTL** — ارقام فارسی، تاریخ جلالی (تبدیل الگوریتمی، بدون
  بستهٔ بیرونی)، بازه‌های زمانی طبیعی («۳ دقیقه و ۱۲ ثانیه») و لحن
  مهندسی.
- **کلاینت REST تایپ‌شده** (`lib/api/client.dart`) برای کل سطح
  `/api/v1`: سلامت، استریم‌ها (CRUD + شروع/توقف)، تشخیص‌ها (+ برچسب‌ها)،
  رویدادها، متریک‌ها (بازه‌بندی و زنده)، مدل‌ها، نشست‌ها، گزارش‌ها
  (JSON/CSV) و تنظیمات. خطاها به پیام فارسی نگاشت می‌شوند
  (شبکه → «ارتباط با سرور برقرار نشد»، 404 → «موردی یافت نشد»،
  503 → «سرویس پردازش در دسترس نیست»…).
- **WebSocket دست‌ساز socket.io v4** (`lib/ws/ws_service.dart`) روی
  `web_socket_channel` خام: دست‌دادن `40`/`40{"sid":…}`، عضویت با
  `42["subscribe",…]`، پاسخ پینگ `2`→`3`، اتصال مجدد با backoff نمایی
  سقف‌دار (۰٫۵ تا ۸ ثانیه) و اعمال مجدد عضویت‌ها.
- **هفت پرده** با حالت بارگذاری/خطا/خالی: نمای کلی، استریم‌ها (ساخت/
  ویرایش/شروع/توقف/حذف)، جزئیات استریم (صحنهٔ زنده با CustomPainter —
  پس‌زمینهٔ صحنه + اشیا + جعبه‌های تشخیص + ROI + خط عبور — و پنل متریک
  زنده و رویدادهای اخیر)، رویدادها (فیلتر + صفحه‌بندی + نمایش JSON
  خام)، تشخیص‌ها (فیلتر + صفحه‌بندی)، تحلیل‌ها (شمارش دسته‌ها + نمودار
  خطی تاخیر با CustomPainter، بدون بستهٔ نمودار) و تنظیمات (نشانی سرور +
  آزمون ارتباط + رجیستری مدل‌ها + درباره).

## پیش‌نیازها

- Flutter نسخهٔ پایدار با Dart **3.4 یا جدیدتر** (تست‌شده با Flutter
  3.47 / Dart 3.13).
- سرور EdgeVision در حال اجرا: داشبورد Next.js روی پورت `3000` و
  سرویس پردازش (engine-service) روی پورت `3003`.

## ساخت و اجرا

```bash
cd mobile
flutter pub get
flutter run            # روی دستگاه/شبیه‌ساز متصل
```

نشانی پیش‌فرض سرور بر اساس سکو:

| سکو | نشانی REST | WebSocket (خودکار از REST ساخته می‌شود) |
| --- | --- | --- |
| شبیه‌ساز اندروید | `http://10.0.2.2:3000` | `ws://10.0.2.2:3003/socket.io/?EIO=4&transport=websocket` |
| دسکتاپ / دستگاه واقعی | `http://localhost:3000` | `ws://localhost:3003/socket.io/?EIO=4&transport=websocket` |

نشانی سرور از داخل خود برنامه (پردهٔ «تنظیمات») قابل تغییر است؛ تغییر
آن اتصال REST و WebSocket را دوباره برقرار می‌کند.

> نکتهٔ معماری: برخلاف مرورگر (که از طریق گیت‌وی و XTransformPort وصل
> می‌شود)، کلاینت‌های بومی مستقیماً به سرویس پردازش روی ۳۰۰۳ وصل
> می‌شوند — بدون واسطه.

## تحلیل ایستا و آزمون‌ها

```bash
cd mobile
flutter analyze
flutter test
```

وضعیت راستی‌آزمایی‌شده در sandbox ساخت (Flutter 3.47.6 stable / Dart 3.13.5):

- `flutter pub get` — موفق.
- `flutter analyze` — **No issues found** (صفر خطا/هشدار/اطلاعات).
- `flutter test` — **۲۶/۲۶ سبز** در سه اجرای پیاپی (`test/widget_test.dart`؛
  آزمون‌های Dart خالص برای ارقام فارسی، جداکنندهٔ هزارگان، تاریخ جلالی
  با مرجع ICU persian — از جمله ۲۲ بهمن ۱۳۵۷ — و بازه‌های زمانی).

توجه: SDK Flutter از قبل در `/tmp/flutter` مستقر بود و در sandboxهای دیگر
ممکن است در دسترس نباشد؛ در محیط خودتان همین دو فرمان را اجرا کنید
(CI نیز `flutter analyze` را روی رانرهای گیت‌هاب اجرا می‌کند).

## ساختار

```
mobile/
├── pubspec.yaml            # http + web_socket_channel (تنها دو وابستگی)
├── lib/
│   ├── main.dart           # پوستهٔ RTL، ناوبری، بنر ارتباط
│   ├── api/client.dart     # ApiService تایپ‌شده + نگاشت خطای فارسی
│   ├── api/models.dart     # مدل‌های داده با fromJson سازگار
│   ├── ws/ws_service.dart  # پیاده‌سازی دستی socket.io v4
│   ├── screens/            # هفت پرده + اجزای مشترک
│   └── utils/              # persian.dart (جلالی/ارقام/مدت) + theme.dart
└── test/                   # آزمون‌های واحد و ویجت
```

برای افزودن سکوهای اندروید/دسکتاپ به این منبع، `PLATFORMS.md` را
ببینید.
